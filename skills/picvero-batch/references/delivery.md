# 最终交付：回复内套图预览＋完整 HTML

主入口默认套图完成后，用本页组织最终回复。用户已确认这种呈现方式，后续直接采用，不再逐次询问要不要图廊或 HTML。只审图、只写文字、单张修改等明确范围优先，不为套用格式扩展任务。

## 固定阅读顺序

1. **完成标题**：`「本次主题或商品名」电商素材已完成`。主题来自本次设计，不照搬案例中的“黑得出众”。若部分图位失败，标题和说明如实表达已完成部分。
2. **回复内图片展示区**：左侧一张大图，右侧纵向缩略图；点击切换大图，选中缩略图有清楚边框，下方显示当前图名和序号。默认展示主视觉；按实际交付顺序放入本次图片，保留完整比例，手机宽度可操作。
3. **主入口链接**：加粗的 `打开完整展示页 →`，指向本次实际 HTML。HTML 是用户查看完整成果的主入口，包含整套图片、商品介绍与设计特点，电脑和手机均可读，可放大查看并保存原图。
4. **一句交付摘要**：按实际结果填写图片、标题、卖点、商品描述和 HTML 数量或范围；不固定宣称每次都有五图或全部成功。
5. **两个辅助入口**：`下载全部素材` 和 `查看上架文案`，分别指向实际 ZIP 与文案文件。
6. **必要时的一句说明**：只说明本次具体待核对或未完成事项。没有问题时省略，不给所有商品附加固定警告；已知细节无法确认时仍保留真实状态，不为简洁而写成已通过。

最终回复直接呈现成果，不加“示例回复如下”、重复欢迎词、过程日志或提示词正文。图片工具已展示的逐张结果不再整段堆叠；用最终展示区集中浏览。内部记录、完整提示词可留在制作目录或下载包内。

## 回复内展示区的实现

- 有可用的 `visualize` 技能时，读取当前环境提供的该技能，按其最新要求生成并在最终回复嵌入可交互片段。复用 [图廊模板](gallery-fragment.html)，填入本次真实图片与名称；模板是布局起点，宿主要求优先。没有该能力时，使用宿主明确支持的原生图片组；均不支持时展示一张实际主视觉并保留完整 HTML 链接，不能把普通图片谎称为可点击切换的图廊。
- 只使用已经生成并实际查看的本次图片。制作预览所需的缩略图压缩、格式转换和数据嵌入属于交付整理，不再调用图片生成工具，也不改写原尺寸交付图片。
- 片段使用唯一根 ID；模板默认 `picvero-delivery-gallery`，一条回复有多个片段时同时替换其 HTML、CSS 与脚本中的根 ID。将模板中的 `__PICVERO_GALLERY_IMAGES__` 替换为 JSON 数组，每项为 `{"title":"图位名称","src":"data:image/jpeg;base64,..."}`。转义 JSON 内的 `<` 为 `\u003c`，不要把图片名称拼成可执行 HTML。
- 预览图片可使用适度压缩的显示副本；检查片段满足当前宿主的体积和资源限制。当前已验证方案为约 640 像素 JPEG 的内嵌数据图，五图片段小于 1 MB。原尺寸图片留在交付目录与 ZIP；不以预览副本替代下载原图。最终片段不能留下占位符或依赖不可访问的本地图片 URL。
- 完成后确认主图能显示、缩略图切换会更新主图/名称/序号，窄屏不横向溢出。用一次必要的页面与交互检查即可；修复本地显示问题不触发商品图重生成。
- 回复内图廊是独立的预览组件，不依赖用户另开页面；完整 HTML 仍须保留全部成果。多商品、多风格或多角度按实际生成内容分组，不把场景变化标成新的拍摄方位。数量较大时可在回复展示明确标注的代表图，完整内容放在 HTML 中。视角按实际画面命名，有推演的图在名称或图注中补“AI 推演视角”，与实拍依据支持的角度区分；具体标注按 [多角度约定](multi-view.md)，无需在商品图内强制加字。

## 多款商品一起交付

主入口默认每款都有完整图片、文案和 HTML；回复里的预览取舍不缩减实际制作范围。

- 每款使用独立子目录保存图片、`商品文案.md` 和 `详情页.html`，目录名称能对应自动归类后的商品名称或本地编号。
- 整批提供一个汇总 HTML 作为“打开完整展示页”的主入口，展示所有商品与完成情况，并链接到各款完整详情页。提供整批 ZIP 和按款编排的文案汇总，避免用户逐套找文件。
- 三款这类小批量可按商品分别展示可切换图廊，每个片段使用唯一根 ID 并满足宿主的大小限制；数量较大时可用每款代表图作为回复预览，清楚标明预览范围，全部图片仍进入各款 HTML 与下载包。
- 摘要按实际完成情况写明款数与总图数，例如“三款商品、十五张电商图，各配完整文案和详情页”。有失败或未完成款时逐款简短标明，不用其他款补足数量，不将原照张数当成款数。

## 回复骨架

下面是结构说明，实际交付时替换全部内容和路径、去掉方括号说明。路径采用当前宿主支持的可点击格式；本地文件使用真实绝对路径，不硬编码示例用户目录。

```text
## 「本次主题」电商素材已完成

[本次实际图廊的宿主内容引用，不是普通文本占位符]

**打开完整展示页 →**（加上本次 HTML 的真实链接）

本次包含 **实际图片数张电商图、实际标题数个标题、实际卖点数条卖点、商品描述和 HTML 详情页**。

下载全部素材（本次 ZIP 链接） · 查看上架文案（本次文案链接）

[仅在有具体问题时，用一句话说明]
```

完整包至少包含实际图片、文案和 HTML，HTML 内的资源链接使用相对路径，解压可用。仅做图片的任务省去未请求的上架文案与详情页，保留图廊、实际图片预览页和下载入口。仅做文字的任务直接交付相应文字，不创建空图廊。
