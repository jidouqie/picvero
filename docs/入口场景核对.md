# 主入口场景核对

0.5.1 的规则检查清单。它用于核对入口和共用说明，未执行独立模型评测，不计入自动测试数量。

| 场景 | 预期处理 |
| --- | --- |
| 主入口＋单件商品实拍，无要求 | 五张独立套图＋上架文案＋详情页，不停在首图 |
| 主入口＋同件商品的正侧面 | 合并参考，仍是一件商品的默认整套 |
| 原图已经白底 | 仍策划主视觉、展示、特点、场景与设计解析 |
| 只要一张 | 一张一次，不扩展套图 |
| 指定三张 | 三个图位各一次，不覆盖为默认五张 |
| 只要图片，不要文案 | 完成图片，省去额外文案和详情页 |
| 只审图 | 不调用生图 |
| 只写标题 | 直接交标题，不要求生图 |
| 已说改成英文，随后只发图 | 继承英文要求，不进入新商品整套 |
| 只发竞品参考，无自家原图 | 提炼样式并请求商品原图，不挪用竞品事实 |
| 只发外文成图，无翻译要求 | 快速检查并交结论；不主动优化，不自选目标语言 |
| 正在等尺寸资料，用户补参数表 | 读资料继续原任务，不重开整套 |
| 第一张存在纹理未知 | 记录未知，继续其余四张与文案，不自动重试 |
| 某张明显失败或工具失败 | 保留失败记录，完成剩余任务，交付中说明缺失／问题 |
| 第二张返回后觉得还能更好看 | 不自动再生成 |
| 用户说修改第二张 | 只为第二张制作新版本；次数已满就建立关联修改任务，不重做全套 |
| 小纹理差异或轻微光色差 | 快速检查后直接交付，不自动修改或停下来询问 |
| 明确十个 SKU 全部完成 | 分别完成已授权范围，不止于代表商品 |
| 未说明范围的多商品照片 | 完成一件代表商品整套和文案，明确其余进度 |
| 只打开技能，没有资料 | 简短说明套图、文案和详情页能力，再请用户发照片 |

检查不自动代表选用，unknown 不自动通过。五图首轮视觉质量与用户体验还需要真实使用验证，不能从此清单推断。
