# 图片本地化

先识别目标语言、适用市场和图位。提取图片中的原文，并标出看不清的区域；保留型号、品牌、认证与数字的准确形式，产品本体印刷默认保持原样。

形成短对照表：原文、译文、所在区域、是否翻译、需确认项。翻译用该语言自然表达，不添加证据中不存在的性能与承诺。单位换算使用明确数值和计算过程；没有品牌尺码表时不把通用 S/M/L 对照当作实物尺码。

用原图作为内置改图目标，替换指定的营销文案区域，保留商品外观、品牌印刷和布局关系。控制文字长度与换行，不为了保留字数而挤到不可读。

看候选图核对拼写、数字、单位、标签、重叠与截断。字体看不清时标记未知，保留正确的文字对照；默认不自动重生成，修改次数遵从 [共用约定](workflow.md)。不把生成工具正常返回当成翻译正确。多语言共用相同商品事实与品牌规范，各语言独立核对和归档。

交付译图与文字对照。用户只要图片翻译时，不自动改店铺语言、调用店铺后台或发布。
