# 首次公开发布

项目：Picvero 0.5.6。

## 仓库内容

公开技能指令源、共用运行器、构建与安装工具、自动测试、生成后的八个技能目录、项目文档，以及有来源记录的合成／公有领域照片演示。

不包含商家工作目录、会话原照、私人生成素材、个人技能软链接、虚拟环境和凭证。`work/`、`runs/`、`outputs/`、`.agents/` 与本地配置被忽略；版本安装包通过 GitHub Releases 提供。

## 历史演示记录

部分历史示例采用早期名称 Huoying／货映。它们保留制作时的版本、提示、检查结论和原始图像校验值，不代表当前版本重新执行过相同实验。

为公开分发，演示记录中的个人绝对路径已改为 `/path/to/picvero` 或 `/path/to/codex` 示例路径。这些文件是脱敏后的阅读副本，文件本身的字节或旧计划摘要不再适合用作原始运行记录校验。生成图片及其 SHA-256 未因路径脱敏而改动。

## 验证边界

首次发布执行了 44 项自动测试、八个技能的格式校验与源码构建。自动测试覆盖本地运行记录、版本、审核状态、文件引用和安装包，未据此声称商品图精确还原或任何电商平台已批准上架。
