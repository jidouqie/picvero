# 整套视觉与信息审核

实际查看了原图与全部六次内置工具输出。这里记录本次观察结果，不是评分模板或平台审核结论。

| 检查 | 结果与依据 |
| --- | --- |
| 商品识别 | 概览以商品名、完整壶身和两项可见特征组织；第二版副标题已与壶嘴拉开距离 |
| 图位分工 | 概览回答“是什么”，侧柄回答“结构怎样”，细节回答“部件长什么样”，场景回答“如何摆入环境” |
| 视觉对应 | 侧柄指引线落在实际连接处；细节标签与两处原照可见区域相对应 |
| 统一性 | 黑色/白色无衬线主标题、橙色短线与中性背景贯穿；深色特点页与浅色细节页有变化 |
| 新角度问题 | 细节第一版产生过高俯视盖面，已记录 fail；修正版回到原照前视，未沿用初版作为合格细节 |
| 文字避让 | 概览第一版副标题靠近壶嘴，已记录 fail；第二版缩小副标题并保留原文字 |
| 商品条件 | 主要壶体、左右部件、开放式侧柄和旧痕仍可见；刻字与微纹理无法确认精确复原，最新各图 identity 保持 unknown |
| 卖点与包含物 | 无竞品功率、容量、材料成分或认证；场景图片明确杯碟与托盘为布景 |
| 使用范围 | 通用商品附图/详情模块示例，未指定平台第一主图规则，没有平台合规或转化率结论 |
| 阅读检查范围 | 当前工具显示的完整图片上标题、标签和主体层级可辨；未单独渲染手机缩略预览，不声称已通过该项 |

当前交付为有待核对的设计候选。商品原图是参考事实依据，style 参考只是画面方法。所有旧版与实际提示保留；无用户选用记录。
