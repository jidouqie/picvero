# 真实网页照片测试

本次在八个技能开发与 40 项自动测试完成后，选取一张普通公开照片进行测试。照片来自 Wikimedia Commons，作者 Mohanraj55，页面标注 CC0；来源与哈希见 [source.json](source.json)。

[原图页面](https://commons.wikimedia.org/wiki/File:Mug_image.jpg) · [本地原图](source.jpg)

原图为 960 × 1280 的带柄容器照片，位于花纹布面上。没有商品参数表，不能确认材质、容量或尺寸。本例将其识别为绿白带柄水舀，只使用照片可观察的颜色、长柄和导流口。

## 已测试的工作流

CSV 清单导入 → Codex 查看实拍并整理事实 → 使用品牌要求 → 独立制作白底、场景、中文特点图 → 将中文图改成英文 → 原图对照审核 → 文件检查 → 带状态的草稿交付。

实际使用 Codex 内置 image_gen，四次调用生成四张图片。没有调用独立生图 API 或配置其他平台密钥。实际提示保存于 [native-prompts.json](native-prompts.json)。

## 结果

| 项目 | 结果 |
| --- | --- |
| 图片生成与落盘 | 4 张均完成，1254 × 1254 PNG |
| 元数据检查 | 方形、尺寸下限、格式、体积等已覆盖项目通过 |
| 中文内容 | 绿白相间、开放式长柄、导流口设计均可读 |
| 英文内容 | Green & white finish、Open-ended handle、Pouring lip 可读，无中文残留 |
| 主要结构 | 右侧长柄下端悬空、左侧导流口与主要绿白分布仍可见 |
| 精细保真 | 生成后表面斑点／纹理被重构，低清原图不能验证；4 张均标为 inconclusive |
| 默认合格交付 | 被正确阻止，未将待核对图片冒充合格 |
| 本例交付 | 使用明确的 drafts 模式输出，图片状态仍为有待核对 |
| 店铺发布／用户选用 | 均未执行 |

这次证明了工作流和内置工具可运行，也暴露出原图不足时的保真边界。四张图片不是实际在售商品的新实拍，不能据此声称真实材质被恢复、已通过平台审核或提高销量。
