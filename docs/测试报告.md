## 内置图片工具验证

HY-17 是本次生成的虚构商品，只用于验证工具与工作流。没有对应真实店铺、材质证明或销量。

| 环节 | 实际观察 |
| --- | --- |
| 生成参考样本 | 得到普通桌面场景中的三格收纳盒，含 HY-17 标签和黄色圆点 |
| 用本地原图改图 | 得到干净白底候选，原有三个分隔与标识仍可见 |

[演示与素材说明](../examples/README.md)包含原图、失败候选、修正版、实际制作说明和样本哈希。

固定样本回放仅复用本轮已记录的视觉判断，并严格核对图片哈希；不冒充新的生图或新的视觉评估。

## 自动测试重点

- 缺商品原图、重复 SKU、越界编号被识别；风格参考不能充当商品事实来源。
- 未知事实不能作为已确认的卖点引用。
- 原图、快照、计划、结果文件变化，不能沿用旧记录。
- 未生成或文本文件不能冒充图片产出；重复记录同一结果保持幂等。
- 空审核模板、缺参考哈希、旧版本审核被拒绝。
- unknown 不自动通过；审核通过不等于用户选用。
- 失败原因保留，制作次数有界，旧版文件留存。
- 导出默认不把未核对或被拒绝图片列为可交付候选；未纳入项有说明。
- HTML 文本转义，清单不包含内部 source_path，ZIP 文件路径为包内相对路径。
- 带点的交付版本名保留完整。
- 单技能安装资源完整；生成目录手工改动和已有同名技能受保护。
- 统一更改项目名与前缀后，所有技能名称和默认提示同步更新。

## 验收范围

HTML 预览做了静态结构与本地链接校验。尝试在 Chrome 打开本地页面时，被浏览器 URL 安全策略阻止，因此没有完成浏览器中的实际排版与交互验收；没有绕过该策略。图像结果本身通过工具输出逐张查看。

图片元数据使用标准库检查。Pillow 在本轮标准库运行环境中未安装，因此可选的完整解码与透明像素检查没有实测；它们不会被报告为已经通过。PyYAML 仅用于独立的官方技能格式验证，不进入运行依赖或技能包。

## 尚未验证

- 真实卖家商品的保真程度、节省时间与采用率。
- 多语言图片、密集标签、玻璃与反光材质、服装试穿等困难样本。
- 多 SKU 大规模连续生成的效率、额度表现与稳定性。
- 所有 Codex 版本和账户是否提供相同内置图片工具。
- 平台当前全量图片规则、实际审核结果及销售效果。
- 生成式视频与音频没有纳入实现。

本轮交付为可安装的 0.1.0 首版和本地工具。工作流入口存在不等于对应品类已经全部实测，后续按真实商品测试结果扩展。
