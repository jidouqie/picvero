# 货映 0.2.0 开发与真实照片测试报告

日期：2026-09-15。临时名称仍为货映，技能前缀为 huoying-。

## 开发完成范围

当前定义的八项技能入口、共用工作流、本地任务记录、构建与安装已实现。图片制作仍由 Codex 内置图片工具执行，本地运行器没有接入外部生成服务或 API Key。

本次补齐：

- 历史版本查看、审核与选用，用户可以明确回到第一版。
- 导出优先使用用户选定版本；支持只导出选用项。
- 审核结果与用户选择独立保存，重新检查不会悄悄抹除用户选择。
- CSV 清单转请求草稿，支持引号内逗号、UTF-8 BOM、本地相对图片路径及重复 SKU 检查。
- 任务详情返回已核对路径、事实、品牌要求与版本历史，方便继续。
- 记录图片时状态写入失败会清理未提交副本，后续可以重新记录。
- 有指定文案的图片不能跳过文字检查。
- 导出过程中重新核对图片与参考副本哈希，避免拿到变化后的文件。

## 自动验证

40 项自动测试通过，八个技能通过官方格式校验。结果见 [validation-0.2.0.json](validation-0.2.0.json)。

测试包含原有版本、状态、来源与打包规则，以及新增的旧版选择、选用项导出、历史审核、CSV 和中断恢复。项目中的八个自动发现链接仍指向最新构建文件。

## 按要求进行的网上照片测试

完成代码与自动验证之后，选取 Wikimedia Commons 的 [Mug image.jpg](https://commons.wikimedia.org/wiki/File:Mug_image.jpg)。作者 Mohanraj55，源页标注 CC0；原图为 960 × 1280 JPEG，画面是一只放在花纹布面上的绿白带柄容器。源照片不是本项目生成的虚构样本。

通过实际技能指南执行：CSV 导入、看图、商品事实整理、共用风格、套图、中文说明、英文翻译、原图对照、技术检查和交付。

| 输出 | 制作结果 | 检查结果 |
| --- | --- | --- |
| 白底图 | 已生成，1254 × 1254 PNG | 背景处理完成，细纹理待核对 |
| 台面场景图 | 已生成，1254 × 1254 PNG | 主要结构可见，无新增配件，细纹理待核对 |
| 中文特点图 | 已生成，1254 × 1254 PNG | 三条指定文字可读，标注对应可见特点 |
| 英文特点图 | 已生成，1254 × 1254 PNG | 指定英文可读，无中文残留，长文本换行 |

四张图的长柄、导流口与主要颜色分布仍可辨认。但生成结果对表面细小斑点和纹理进行了重构，原图不足以证明其准确性。因此四张均记录为 inconclusive，没有包装成“完全保真”。

默认合格交付被正确阻止；本例用显式 drafts 模式导出，保留“有待核对”状态，便于查看真实效果。没有标记真实卖家选用，没有发布店铺。

## 结论与限制

这次验证了真实外部照片可以进入原生套图、翻译、审核和交付流程，也验证了不确定结果不会被自动认定为合格。单张低清照片的细节还原不是纯提示词能够保证的能力，使用真实卖家素材时仍需对照实际商品。

本次未验证复杂试穿、透明商品、大规模连续生成、所有平台审核或销量效果。HTML 做了静态结构与资源引用检查，没有新增浏览器实际排版验收。生成式视频本就不在这八项技能的实现范围内。
