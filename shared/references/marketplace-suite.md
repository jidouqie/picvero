# 从实际电商套图提炼设计

用于套图策划、用户要求“参考平台优秀商品图”“照这个商品链接的样式做”，以及审核成套图片的信息表达。与 [视觉设计](visual-direction.md) 配合：本页决定每张图讲什么、如何证明，视觉设计决定具体配色、空间和排版。

## 有参考时，先看完整图组

用户给了链接或参考图，查看实际商品主图、附图与详情模块，记录平台、商品、访问日期和真正看过的图位。只有标题、搜索摘要或小缩略图时，不宣称已经看清其版式；打不开的部分标为未查看，继续使用可见参考。

从当前商品同品类、相近客单价/品牌定位、相同图位用途的参考中选适用的方法。没有这些资料时不推断真实售价或客群，可以提出本次视觉定位。通常少量完整图组比大量孤立海报更有用。默认不要求每次联网，现有规则已足够时直接执行；用户要求搜索时再查看当前实际页面。

拆解四件事：

- 阅读顺序：商品识别、主要利益或特征、局部依据、使用/选择说明，分别在哪张完成。
- 画面骨架：主体大小、裁切、文字区域、局部放大、对照或步骤组合、背景层次。
- 信息层级：主标题只承担一个主要信息；副标题解释；数字、图标、脚注有事实依据。
- 整套统一项：标题位置/字重、背景家族、品牌色、间距、图标和标注语言；哪些图刻意改变构图。

参考图只提供表达方法，不能提供本商品的品牌、材质、功率、尺寸、销量、评价、认证、获奖或售后事实。原图有包装/多个规格/另一 SKU 时，先分清当前售卖项。不要原封不动移植整页独特文案或品牌资产。

## 先写图位计划，再写提示词

对每个计划图位记录以下内容，可放入本次 `creative-brief.json` 或 Markdown；这是 Codex 策划记录，不是运行器新增必填字段：

| 字段 | 要回答的问题 |
| --- | --- |
| 图位与用途 | 平台主图、附图、详情模块还是广告素材？ |
| 买家问题 | 这一张让买家知道什么？ |
| 核心信息 | 商品名、一个利益点，或一个具体可见特征 |
| 依据 | 对应商品原图位置、已确认参数或文档；没有就不写成事实 |
| 视觉表达 | 全貌、真实局部、使用动作、对照、选择表或步骤，哪种最能解释？ |
| 镜头与变化 | 机位、摆放、景别、表现方式是什么，与其他图有何明显差别？ |
| 视角依据 | 哪些原照支持该镜头，哪些部分是 AI 推演？按 [多角度约定](multi-view.md) 标注 |
| 参考方法 | 借鉴哪个已查看图位的构图/层级？需要哪些适配？ |
| 不变项与避让 | 商品结构、标识、色块，以及文字不能遮住的部件 |

不要用“高端、大气、精致”代替具体策划。标题优先帮助识别商品或理解特征，例如“开放式侧柄”比连续使用情绪口号更适合结构说明。情绪文案可用于品牌/场景图，不能取代整套的信息内容。

## 可组合的图位方法

| 买家问题 | 可采用的画面 | 需要的资料 |
| --- | --- | --- |
| 卖的是什么？ | 商品全貌占主导，名称与少量关键特点；或符合指定用途的无文字主图 | 本商品原图及售卖数量 |
| 为什么值得关注？ | 一个核心信息 + 大商品 + 一处相关证据，避免一张塞满卖点 | 已确认利益点；只有外观资料时写具体设计特征 |
| 特点在哪里？ | 全貌定位 + 一个局部放大，细线指向真实部件；或并列的可见细节 | 能看清该细节的实拍。放大只是展示，不能生成新构造/微纹理 |
| 怎么用、在哪用？ | 有依据的真实使用场景或步骤；构图服务于动作 | 对应使用资料/可确认用途，步骤需有真实依据 |
| 多大、适合什么？ | 参数图、尺寸对照、兼容表或规格选择 | 本 SKU 的实际数值、测试/尺寸表；不能借用竞品 |
| 收到哪些东西？ | 售卖物与包装/配件一一对应的展示 | 明确包含物；场景道具不能被误读为赠品 |

按数量、用途与证据取舍，不把未知背面、剖面、使用步骤或参数当作已证实的商品信息。默认五个图位的安排见 [整套交付](launch-kit.md)，主入口同时交完整文案与详情页。仅一张照片时也可推演不同机位和商品姿态，结合主视觉、纯净展示、已知设计特征和合理场景形成有变化的整套，按 [多角度约定](multi-view.md) 区分实拍依据与 AI 推演；缺细节实拍时不强求微距图。用户给定数量和范围优先。

## 视觉风格按表达任务选择

- **清晰功能型**：浅色或中性色底，大主体、粗细明确的标题、少量强调色，信息与实物关联。适合规格/结构清楚的产品。
- **精致生活型**：有目的的日常环境、自然光和少量道具，商品与使用关系清楚。适合家居、厨房等场景；道具与售卖包含物分开。
- **技术解释型**：深色/明暗对比、局部标注、端口/连接示意，或数据对照。资料不足时只画已见外观，不把示意结构当成真实内部。

这些是可组合的方法，不能等同于某个平台唯一风格。长详情页的模块需要重新编排后才适合方形附图；带文字营销图不能直接视作平台第一主图。当前平台要求需按站点、类目、图位另行核对。

沿用原店铺规范；无规范时从商品和参考提出一套本次方案。共用配色与标题体系，各张用不同的表达机制。不要默认每种商品都是洞石展台、植物投影、宋体诗句，也不要把粗黑体/深蓝背景反过来固定为新的通用模板。

## 完成后按整套检查

结合 [审图](review.md)，除了逐图保真，再查看整套缩略效果与主要文字；工具支持时按接近手机阅读宽度检查，不把大图可读当成小图一定可读。

1. 第一张能否识别商品与用途？重要部件是否完整？
2. 各张是否新增有用信息，商品视角、姿态、景别和表现方式是否有明显差别，还是只换了背景和口号？
3. 每个卖点的视觉证据是否来自当前商品？标注是否真的指到相应部位？
4. 标题、商品、说明、脚注是否有稳定层级，且无挤边/截断？
5. 裁切、局部图、比例和道具有没有造成结构或包含物误解？
6. 套图是否达到本次选定风格，同时保留商品本色、部件与成色？

把整套发现记录为本次 `suite-review.md` 或等价说明，并在逐图审核中落实相关问题。缺项保持未知，不为“对标优秀套图”跳过保真检查。
