# 电商视觉设计

用于主入口默认套图，以及场景图、品牌主视觉和卖点图。商业视觉完成度是默认要求，不等用户再补一句“做高级一点”。商品本身与已确认事实仍保持稳定；把设计工作放在布景、光线、构图、配色和信息表达上。

成套素材先按 [实际电商套图](marketplace-suite.md) 安排买家问题、核心信息和视觉证据，再决定以下设计细节。参考网页或图片时提炼其信息结构、构图和视觉体系，按当前商品重新设计。

## 每件新商品的默认完成度

这套标准适用于后续不同品类的商品，无需用户再次强调“像上一组一样”“多角度”或“做高级一点”。用户确认的是视觉完成度与交付体验；具体商品仍需按本次参考独立识别和设计。

不设品类白名单。交换机、瓶盖、开瓶器、用户称作“大象牙膏”的主体以及非常规物品，都按同一商业展示完成度策划；物品普通、体积小、陌生或不符合常见审美，不构成降为简单换底或少交内容的理由。不要因为名字特别就擅自美化成另一种商品。先看图识别主体，再决定怎样展示其形态、尺度关系、可见特点和使用语境。

镜头选择服从当前主体：交换机可突出机身与已有实拍支持的接口布局，瓶盖可用小物棚拍和有依据的边缘结构，开瓶器可展示整体轮廓与真实开口部件，名称特殊或含糊的主体先按照片判断外形与可见内容，不因名字带“牙膏”就擅自归为口腔用品。示例只是适配思路；遇到未列出的物品也自行设计。陌生名称不提供材质、用途或功能证据；无法确认用途时以外观展示为主，不硬造使用场景、内部构造或功效。

| 项目 | 每次制作时落实 |
| --- | --- |
| 商品专属设计 | 根据本商品的形态、可见特征、使用情境与已有品牌要求选择主题、配色和场景；不给新商品自动套用上一件商品的标题、黑绿配色、悬浮展台或鞋类镜头 |
| 第一眼吸引力 | 首图有明确主体、光影与构图选择，达到完整商业主视觉的设计要求；不需要先出普通换底样图再让用户要求升级 |
| 整套变化 | 图位分工、机位、摆放、景别和表现方式共同变化，依照 [多角度约定](multi-view.md) 策划；商品本身与视觉语言保持连贯 |
| 信息有用 | 纯净图看清商品，特点页讲具体设计，场景符合用途；标题和卖点取自本商品依据，资料不足时用可见特征，不套用别的商品功效 |
| 成果完整 | 主入口按 [整套交付](launch-kit.md) 配齐五张独立图、标题卖点与描述、配图文案、完整 HTML 和下载包；页面风格随商品设计，回复沿用 [交付格式](delivery.md) |

这些是每次策划与交付的执行标准，不是所有品类效果相同或百分之百保真的承诺。透明反光、细小标识、复杂结构等难点按本次原照处理；一张或多张原照均可开始，实拍依据与推演部分分别记录。明确的用户数量、原角度、纯白或只做文案等要求优先。

把标准落实在首次生成前的图位方案中，完成后只随现有的一次快速核对检查实际结果。维持每图一次，不因本节增加自动修正、评分门槛、审批或新一轮等待。

## 先确定图片用途

默认套图从一张有吸引力的商业主视觉开始：围绕商品选择大胆但协调的明暗与色彩对比、有空间层次的场景，以及清楚的主题和商品焦点。再用纯净展示、特点页和场景页展开。内部一次定好整套，不先出普通换底图等待用户要求升级。

- 基础展示／有明确平台要求的主图：重点做光线、构图、边缘和背景整洁；按该用途的规则决定是否放文字与道具。
- 场景或品牌主视觉：安排有前后层次的环境与光线，让商品成为画面中心。
- 特点页：以一到两个重点组织版式，文字和细节区域形成清楚的阅读顺序。
- 商品名与核心特点优先清晰；场景图可用情绪标题，其他图不靠连续口号填充。使用局部放大、对照或步骤前，先确认有对应的真实资料。
- 用户只改当前图片时，仅更新本次视觉方案，不自动覆盖店铺长期规范。

## 把“高级感”写成可执行的画面选择

制作前形成简短的视觉方案，信息足够时直接执行，不让卖家填写设计参数表：

1. 主色与辅助色：从商品或已有品牌选择一套协调配色，明确对比关系；通常一个主色、一种中性色和少量点缀即可。
2. 布景与空间：选择与商品适合的台面、展台、墙面、弧形背景或真实使用环境。空间要有前后和光暗关系。
3. 灯光：明确主光方向、软硬、接触阴影与背景亮度。让产品从环境中分离，不能靠过度锐化增加不存在的细节。
4. 构图：确定商品焦点、画面占比、文字区与留白。保持已知商品比例与识别特征，主动安排不同机位、摆放和景别；无实拍覆盖的角度按 [多角度与多图参考](multi-view.md) 标明 AI 推演。
5. 排版：标题、辅助文字、特点说明形成明确层级。对齐与边距一致，长文字合理换行；不靠堆满大字、描边、箭头和贴纸表达精致。
6. 场景辅助物：少量且服务于画面，不遮挡关键结构，也不让人误解售卖包含物。

默认五张套图至少体现主视觉、纯净摄影、信息排版与场景四种不同表达。需要大标题时可以用有力度的字体与克制的短句，但不虚构品牌、参数或性能。布景、主光和排版应有明确设计选择；“更震撼”不能通过改变商品材质、增添配件或重画精细纹理实现。用户已有朴素风格或纯白要求时遵从。

颜色、摄影布景和字体是设计选择；材质、容量、功效和认证属于商品事实，不能混为一谈。

## 三种可组合的方向

| 方向 | 适合的任务 | 可使用的方法 |
| --- | --- | --- |
| 清爽品牌摄影 | 通用日用品、清晰展示 | 有层次的浅色背景、柔光、自然投影、协调配色 |
| 编辑式特点页 | 卖点、细节介绍 | 不对称版式、色块、序号、细线、可读的标题层级 |
| 品牌广告主视觉 | 明确希望更精致或更有吸引力 | 建筑感布景、适合的展台材质、侧向光、前景层次、主视觉大标题 |

以上是方法而不是固定模板。绿色商品可以尝试墨绿与暖白，其他颜色和品类应重新判断。用户有品牌或审美要求时优先采用，不能把本次案例的洞石、植物、绿色背景强加给所有商品。

英文装饰文字不是必需元素。优先使用用户的品牌与语言；没有品牌时不编造品牌名。可以创作适合画面的短标题，但不要把审美文案写成未经证实的产品优势。

## 套图统一，图位分工

共用商品身份、配色关系和字体层级；机位、摆放、光线方向、明暗和布景按图位变化。主视觉、棚拍、场景与特点页应像不同镜头，共同构成一套。策划时对比商品轮廓与姿态，避免五张都沿用同一原图的构图；仅换背景、文字或裁切不算多角度。

可采用大主体搭配短信息、全貌与局部对应、场景与说明组合等方式。学习真实电商图的信息密度与证据表达，不把字体、展台或某个颜色当成所有商品的固定模板。

特点需要放大时，展示原图已经可见的部分，不生成不存在的内部结构或新微纹理。图片上的局部展示应与主商品保持一致。

## 交付前再看一次审美

除原图对照外，检查：

- 第一眼能否找到商品与主要信息。
- 布景是否有层次，是否与商品形成合适对比。
- 标题、正文、装饰元素是否区分主次。
- 文字是否对齐、可读，是否挤边或遮挡。
- 场景是否像一次有目的的摄影或设计，而不只是简单换底色。
- 装饰是否压过商品，是否把原本的产品变成另一种材质或档次。

用户认可物品还原、只要求更漂亮时，沿用该版本作为外观基线，并同时保留原始实拍参考。针对审美进行修改，不反复重做已经接受的商品结构。
