# Picvero：发商品照片，交套图与文案

**发来商品照片，自动按款归类，发几款就完整做几套。**

在技能列表调用 `$picvero` 并发送商品照片。背景、场景、构图、光线和排版由 Picvero 自主设计，不用先写提示词或逐张批准。

## 默认一次交齐

- 每款五张独立商品图：商业主视觉、纯净展示、核心特点、场景氛围、设计解析／购买信息。
- 每款三个商品标题、三到五条有依据的卖点、商品描述，以及配图短文案。
- 每款使用本次图片的详情页 HTML 草稿；多款另有汇总展示页，全部图片和文案统一打包。

商业主视觉默认就有完整设计，商品突出、光影鲜明，整套有统一的字体与配色，各张内容和布局有变化。未知品牌、材质、规格和性能留在待补资料中，不虚构进成图。

每个图位默认只生成一次。五张图是五次不同内容的制作，不是同一张图反复生成。图片会对照原照检查；问题保留在结果中，继续完成其他图片和文案。没大问题直接交付，明显影响使用的问题简短指出；只有你明确要求修改时才制作新版本，不自动增加等待。

## 换商品，标准继续沿用

以后直接发新商品即可，无需再强调多角度、多样式或完整 HTML。不限鞋服或常见日用品，工业设备、小零件、造型商品及非常规物品也按同一完成度策划。Picvero 会重新判断商品特征、设计主题与镜头，默认保持同等的商业视觉完成度与完整交付。具体效果仍受原照和商品复杂度影响；不会把黑鞋案例的配色、标题和布景直接套到所有商品。

## 可以发一张，也可以发多张

Picvero 会查看全部照片后自动归类。同件商品的正面、侧面、背面和细节照合并使用，每张成图选取相应的实拍依据。不同款式、颜色或已知规格变体分别处理；图片里的布景道具不另算商品，同品类也不自动合并成同款。

例如，三张不同产品照片默认做三套，共十五张图，并为三款分别配齐文案与 HTML。三张同一产品的不同角度照则合并做一套，共五张图。无需先给 SKU 清单或逐组确认；只有确实无法分清的组才询问，其他商品继续制作。不会只做一款代表商品后停下。

默认套图改变机位、摆放、景别和表现方式，通常有至少三种观察方向或商品姿态，结合广告、棚拍、场景与特点页。只有一张照片也能生成新视角，图注明确“AI 推演视角”；无实拍覆盖的部分需对照实物核对。明确要求原角度、只换背景或翻译时遵从。

## 收到成果时

默认回复依次显示完成标题、可切换的大图与缩略图、**打开完整展示页**、实际交付摘要，以及 **下载全部素材 / 查看上架文案**。HTML 集中呈现整套图片与商品介绍，可在电脑和手机浏览。没有具体问题时不附加固定警告；展示区复用已有成图，不额外生成图片。

## 明确要求优先

| 你说的话 | 交付范围 |
| --- | --- |
| 只发商品照片 | 自动按款归类，每款五张套图＋完整文案＋详情页 |
| “只做一张白底图” | 一张白底图 |
| “只做三张：主图、卖点、场景” | 指定三张图片 |
| “只要图片，不要文案” | 完成指定图片，不追加上架文案与详情页 |
| “把这张说明改成英文” | 英文图片与文字对照 |
| “只写标题和三个卖点” | 对应文案 |
| “对照原图，只审图” | 检查结论与具体建议 |
| “改第二张的标题” | 只修改第二张，保留原图与旧版 |

只打开技能还没发素材时，会简短介绍整套能力；补发资料或继续已有任务时，接着之前的要求处理。

## 技能名字与用途

列表显示独立英文名称，右侧简介以中文用途开头；调用名继续使用短横线：

| 显示名称 | 调用名 | 用途 |
| --- | --- | --- |
| Picvero | `picvero` | 套图、文案与详情页的一站式入口 |
| Picvero Suite | `picvero-suite` | 专门制作商品套图 |
| Picvero Image | `picvero-image` | 专门制作或修改一张图片 |
| Picvero Listing | `picvero-listing` | 商品标题、卖点、描述与详情页 |
| Picvero Localize | `picvero-localize` | 商品营销图片翻译 |
| Picvero Brand | `picvero-brand` | 店铺图片风格整理与复用 |
| Picvero Batch | `picvero-batch` | 多商品制作与中断续做 |
| Picvero Review | `picvero-review` | 原图对照检查 |

安装 `picvero-0.5.6.zip` 中的 `picvero` 文件夹即可使用完整入口。八技能包提供直接进入某项能力的快捷方式。项目内链接指向生成目录；全局副本不会自动覆盖。如果菜单仍出现旧版的“Picvero · 商品单图修改”等名称，请退出并重新打开 Codex，再检查显示名称和主入口的“五张套图”简介。[官方刷新说明](https://learn.chatgpt.com/docs/build-skills)。磁盘文件更新不能代替菜单显示验证。

生成、检查和用户选用分别记录，细小标识及纹理可能仍需核对。详情页是供编辑与适配的草稿，不自动发布店铺。
