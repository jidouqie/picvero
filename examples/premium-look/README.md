# 品牌视觉升级

用户反馈：物品保真还行，希望更高大上、更好看。本轮保留上一版的物品外观作为基线，升级背景、灯光、配色与排版。

## 两张新稿

- [品牌主视觉](delivery/images/WEB001/hero-v1.png)：墨绿建筑布景、洞石展台、侧向日光与大标题。
- [配套特点页](delivery/images/WEB001/feature-v1.png)：同色系分栏、标题层级和原图可见细节展示。
- [上一版简洁图](delivery/references/WEB001/baseline.png)
- [原图与新稿对照](delivery/index.html)

两张均由 Codex 内置图片工具直接制作，没有外部生图平台依赖。实际提示、配色和本次反馈记录在 [creative-brief.json](creative-brief.json)。

主要结构和绿白纹路按用户已接受的外观基线核对。视觉审核不等同于实物微纹理认证，也没有替用户标记选用。

## Skill 更新

新增 visual-direction.md，将“更高级”拆成配色、空间布景、光线、构图、文字层级和装饰控制。按主图、场景、营销主视觉与特点页区别处理，避免用同一种简单换底色完成所有图位。

本案例的绿色与洞石不作为所有品类的固定风格。当前视觉方案仅用于这次示例，不自动变成长期店铺偏好。

源照片与许可见 [source.json](source.json)。
